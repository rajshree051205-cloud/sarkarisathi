

# 🇮🇳 Sarkari Sathi

Sarkari Sathi is a full-stack web application designed to help users discover relevant Indian government schemes based on categories and eligibility. The platform organizes scheme information in a simple and user-friendly interface to make it easier for citizens to find and understand available government initiatives.

---

## 🚀 Problem Statement

Many people are unaware of government schemes, their eligibility criteria, and the benefits they provide. Information is often spread across different sources, making it difficult to discover relevant schemes.

**Sarkari Sathi** aims to simplify this process by organizing scheme information in one accessible platform.

---

## 💡 Features

### 🎯 Category-Based Scheme Access

Users can explore schemes based on categories such as:

* Women
* Students
* Farmers
* Army Families / Defence Personnel
* Other citizen groups

Each category provides relevant scheme information, benefits, and eligibility details.

### 🔐 User Authentication

* User registration and login
* User profile management
* Password authentication
* Session-based access

### 🌐 Simple Navigation

* Category-based browsing
* Organized scheme information
* Clean and user-friendly interface
* Easy access to relevant scheme details

## 🛠️ Setup & Installation

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/)
* npm
* [MongoDB](https://www.mongodb.com/)
* Git

### 1. Clone the Repository

```bash
git clone https://github.com/rajshree051205-cloud/sarkarisathi.git
cd sarkarisathi
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env` file in the project root:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
SESSION_SECRET=your_session_secret
```

Replace the placeholder values with your actual MongoDB connection string and session secret.

### 4. Start the Application

```bash
npm start
```

If your project uses a development script:

```bash
npm run dev
```

### 5. Open in Browser

```text
http://localhost:5000
```
